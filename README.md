# Cell Formation Problem with Machine Reliability and Alternative Routings

Code accompanying the paper:

> **Hybrid Nature-Inspired Optimization for the Cell Formation Problem with Machine Reliability and Alternative Routings**
> P. Figueroa-Torrez, B. Crawford, O. Durán, M. Jurado-Camacho, et al.
> *Biomimetics*, 11(6), 387 (2026). https://doi.org/10.3390/biomimetics11060387

The code solves a Cell Formation Problem (CFP) where each part can be produced through
multiple **alternative routings**, and machines carry a **reliability** profile (Mean Time
Between Failures) that feeds into the objective function alongside inter-cell movement and
breakdown/outsourcing costs. Solutions are optimized with the Black Widow Optimization (BWO)
and Golden Eagle Optimizer (GEO) algorithms, compared standalone and in three hybrid
configurations.

## Repository structure

```
src/
├── 1boxplotBWO.py            # BWO baseline
├── 2boxplotGEO.py            # GEO baseline
├── 3boxplotGEO_BWO_HA.py     # GEO-BWO hybrid (full hybridization)
├── 4boxplotGEO_BWO_PRCR.py   # GEO-BWO hybrid (parent-crossover reproduction)
├── 5boxplotGEO_BWO_MUT.py    # GEO-BWO hybrid (mutation-based)
└── Funciones/                # Shared algorithm components
    ├── ini_parametros.py     # Problem instance (routes, times, MTBF, costs)
    ├── pre_procesamiento.py
    ├── bwo.py
    ├── geo_func.py
    ├── cal_fitness.py        # Objective function (inter-cell movement + reliability cost)
    ├── reparador.py          # Solution repair operator
    ├── vecNorm.py
    └── grafico.py            # Convergence and boxplot plotting

requirements.txt
```

Each numbered script in `src/` is self-contained: it defines the problem instance, runs the
corresponding algorithm(s) for the configured number of trials, exports the raw results to
`.xlsx`/`.npz`, and produces the convergence and boxplot figures used in the paper.

This repository keeps only source code. Raw result files (`.xlsx`/`.npz`) generated by these
scripts are not included here; they are available upon request.

## Running it

```bash
pip install -r requirements.txt
cd src
python 1boxplotBWO.py   # or any of the other numbered scripts
```

## Problem instance

The CFP instance (machine sequences per route, processing times, part volumes, route costs,
breakdown costs, and machine MTBF) is defined directly in
[`src/Funciones/ini_parametros.py`](src/Funciones/ini_parametros.py).
